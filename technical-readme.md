## Run
Open `index.html` in a modern tablet browser. The package has no external dependencies and makes no network calls.

## Layout
- Primary canvas: 1024 x 768, 4:3 landscape.
- Scaling: fixed 4:3 canvas scales proportionally to fit the viewport.
- Source pages: lossless local PNG page renders for maximum fidelity.

## Navigation
- Previous/next buttons appear briefly on pointer movement.
- Arrow keys, Page Up/Page Down, and swipe gestures are supported.
- The dosage CTA on slide 2 opens slide 3. The close control on slide 3 returns to slide 2.

## OCE CRM
